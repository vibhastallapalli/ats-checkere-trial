How this check works

Each line is lower-cased and stripped of punctuation. Found means a line is exactly a common heading name (for example "EDUCATION" or "Technical Skills:"). Check means the word only appears inside other text, or is letter-spaced like "S K I L L S". Not found means none of the names appear. The line number refers to the text box above, so you can confirm it yourself.
